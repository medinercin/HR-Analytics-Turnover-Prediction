# HR Analytics: Predicting Employee Turnover with ML

## 📌 Overview  
In this project, I used **Decision Tree** and **Random Forest** models to predict whether an employee is likely to leave the company. The goal is to explore patterns in the data and make predictions that could help HR teams take early action.

## 🎯 Goal  
To understand which factors influence employee attrition and build machine learning models that can make accurate predictions based on those factors. This helps turn raw HR data into useful insights.

## ⚙️ What I Did  
- Loaded and explored the dataset  
- Encoded categorical variables like department and salary  
- Visualized class imbalance  
- Built and evaluated decision tree and random forest models  
- Plotted feature importance to see what matters most
